# AI-use disclosure (draft)

- **Building:** we used Claude Code (Anthropic) as an AI pair programmer to write substantial parts of the code, tests and documentation, under our direction. We made the product decisions (small-business focus, Shopify, the name, the hackathons, design direction) and tested and reviewed the results.
- **Inside the product:** Anthropic Claude (Sonnet 5.5 by default) answers questions and proposes hypotheses. All numbers come from deterministic code, and every AI-proposed idea is verified statistically before it is shown.
- **Data:** the case study uses the public UCI Online Retail II dataset (CC BY 4.0), cited in the app. The demo shop is synthetic and labeled as such.
- **Inspiration:** the concept builds on the public write-up of DashAgent (Tableau Hackathon 2025). No DashAgent code or assets were used.
